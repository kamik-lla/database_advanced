# ДЗ № 8: Справочные таблицы для ВР и ДМК (Метео-11)

## Что сделано
Спроектированы и созданы в PostgreSQL таблицы для хранения справочных данных методики **Метео-11**, которые используются при расчётах для приборов **ВР** (ветровое ружьё) и **ДМК** (десантный метеорологический комплект).

## Новые таблицы

### 1. `calc_correction_heights` — высоты зондирования
Стандартные высоты: 200, 400, 800, 1200, 1600, 2000, 2400, 3000, 4000 м.
- `id` — PK
- `height` — высота в метрах (UNIQUE)

### 2. `calc_correction_types` — типы таблиц и срезов
Справочник таблиц 2 и 3 (срезы по температуре, скорости и направлению ветра).
- `id` — PK
- `code` — код среза (например, `T2_TEMP_POS`, `T3_VR_WIND_SPEED`), UNIQUE
- `parent_id` — FK на самого себя (иерархия)
- `equipment_type_id` — FK на `equipment_types` (1 — ДМК, 2 — ВР, NULL — общие)
- `description` — описание
- `header_values` — массив значений-аргументов (заголовки столбцов таблицы)

### 3. `calc_correction` — матрица поправок (Таблицы 2 и 3)
Значения поправок на пересечении высоты и среза таблицы.
- `id` — PK
- `height_id` — FK на `calc_correction_heights`
- `type_id` — FK на `calc_correction_types`
- `row_values` — массив поправок (по столбцам из `header_values`)
- `dir_shift` — поправка направления в делениях угломера
- UNIQUE(`height_id`, `type_id`)

### 4. `device_specs` — характеристики приборов
Паспортные диапазоны и точность измерений ВР и ДМК.
- `id` — PK
- `equipment_type_id` — FK на `equipment_types`
- `parameter_type_id` — FK на `parameter_types`
- `min_value`, `max_value`, `accuracy` — диапазон и точность
- `unit_id` — FK на `units`
- `description` — описание
