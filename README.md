# Db2026

Отдельный репозиторий для курса "Базы данных (продвинутый уровень)"
Учебный репозиторий для курсов:

> 14223-ДБ (ПИ РПО), 14221-ДБ (ПИ РПО)

## Подготовка
1. Откройте каталог _Infra. Переименновать файл _env на `.env`
2. Запустить Docker 
```
sudo docker compose up -d
```
